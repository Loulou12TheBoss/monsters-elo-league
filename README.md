# Monsters ELO League

Crée une application web responsive appelée Monsters ELO League (MEL), une plateforme compétitive de matchmaking pour les équipes Brawl Stars, portée par Monsters Stars. L'interface doit être en français, avec un design e-sport premium, fond noir ou anthracite, vert néon, accents discrets, typographie moderne, animations légères et excellente lisibilité sur ordinateur et mobile. Crée une barre de navigation avec Accueil, Classement, Matchmaking, Équipes et Profil. La page d'accueil présente le concept, un bouton Rechercher un match, un aperçu du Top 5 des équipes, des statistiques de la plateforme et les derniers matchs. La page Classement contient un tableau avec rang, nom d'équipe, ELO, matchs joués, victoires et défaites. La page Matchmaking montre une file d'attente fictive et un aperçu d'affrontement BO3. La page Équipes présente des profils fictifs avec logo, joueurs et tags Brawl Stars fictifs. Utilise des données de démonstration clairement identifiées comme fictives. Crée une interface soignée, cohérente et navigable, avec des composants réutilisables. Pour cette première version, ne crée pas encore de connexion réelle, de base de données, de système ELO actif ni d'intégration API. Ne prétends pas vérifier réellement les matchs. N'ajoute aucune fonctionnalité payante. Le but est de produire une première maquette interactive de haute qualité que nous connecterons à un backend sécurisé dans une prochaine étape.
